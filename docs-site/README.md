# docs-site

The CausalMesh website: one Next.js app serving both the landing page and the
documentation.

| Route                     | Description                                          |
| ------------------------- | ---------------------------------------------------- |
| `app/page.tsx`            | Landing page, composed from `components/landing/`.    |
| `app/docs/[[...slug]]`    | Documentation pages, rendered from `content/docs/`.   |
| `app/docs/layout.tsx`     | The Fumadocs docs layout (sidebar, search, TOC).      |
| `app/api/search/route.ts` | The Route Handler for search.                         |
| `app/layout.tsx`          | Root layout: fonts and shared metadata.               |

Run the development server from the repository root:

```bash
npm install
npm run dev     # http://localhost:3000 — landing at /, docs at /docs
npm run build
```

## Structure

- `content/docs/` — the MDX source for every documentation page. Internal
  links are written with the `/docs` prefix, because the docs are mounted at
  `/docs` rather than at the root.
- `components/landing/` — the landing page components. Interactive ones
  (`Nav`, `Chart`, `Console`, `Agents`, `Routing`, `Primitives`) are client
  components; the rest render on the server.
- `lib/landing/` — landing page data. `results.json` is generated by
  `scripts/export_results.py` from real run artifacts; do not hand-edit it.
- `app/landing.css` — the landing page design tokens as Tailwind 4 `@theme`
  variables, plus the highlighter and guide-grid utilities.
- `lib/source.ts` — the content source adapter. `lib/layout.shared.tsx` holds
  shared layout options.
