---
title: Coordination channels
description: The single typed injection point, and the accounting that makes C0 provable.
---

A channel is the only route by which peer information reaches an agent.
Three exist, and which one is installed defines the arm's information level.

| Channel | Behaviour | Cost growth |
|---|---|---|
| `NullChannel` | Injects nothing; **raises** if given events | zero |
| `TranscriptChannel` | Full conversational history | quadratic, `μ·T(T+1)/2` |
| `MetadataChannel` | Bounded window of scored, typed events | linear, `ν·w·T` |

## Availability and injection stay distinct

The metadata channel records, per turn: `events_available`,
`events_selected`, `events_injected`, `events_dropped`, plus a stored reason
for every selection decision.

<Callout>
An event that was delivered but not selected is a different fact from one
that was never delivered. Collapsing them would make it impossible to tell a
window that dropped information from a relay that never sent it.
</Callout>

Only **injected** events count as known. An event the relay delivered but
the window dropped never reached the agent's context, and treating it as
known would credit an arm with information it did not receive.

## The C0 proof

Each turn records a SHA-256 digest of the injected bytes. A C0 run produces
**one unique digest across every turn** — the digest of the empty string,
repeated — while informed arms produce a distinct digest per turn.

That is a property of what entered the context, not of what the code
intended.

<Callout type="warn" title="A mutation that survived every test">
Feeding delivered events straight into a model's conversation — bypassing
the channel entirely — passed all 21 adapter tests.

Peer information would have reached an agent's context outside all
accounting, so the coordination-byte total would no longer be a complete
account of what the agent knew. C0 stayed safe only *incidentally*, because
`NullChannel` raises; under C2 the leak would have been silent.

`test_the_channel_is_the_only_route_information_takes` now closes it.
</Callout>

The general lesson, recorded because it recurs: **the guarantees most worth
testing are the ones no test naturally covers, because they are properties
of what the code does not do.** Every test written up to that point checked
that something happened correctly. Nothing checked that nothing else did.
