- **BaseFrameworkAdapter**: Introduces a common integration layer that guarantees exactly one authorization path by explicitly routing framework calls through `CausalMesh.execute()` and `execute_async()`. 
- **shared schema translation**: Adds standard-library `inspect`-based Python type hint extraction into OpenAPI/JSON Schema formats, eliminating the need for mandatory external dependencies like Pydantic.
- **GenericAdapter integration**: Upgrades the existing `GenericAdapter` to leverage the new abstraction.
- **LangChain async support**: Expands the existing `LangChainAdapter` with native `ainvoke()` capability seamlessly through `_async_dynamic_handler`, without breaking the existing synchronous usage pattern.
- **backward compatibility**: Both existing adapters maintain their public API. The core `AgentAdapter` protocol simply gained an `acall_tool()` requirement.
- **security/evidence invariants**:
  - The adapter strictly cannot invoke a tool handler directly.
  - A denied async call is proven *never* to await the handler.
  - Result translation isolates and obscures raw Python exceptions from model-facing prompts while logging them appropriately.
- **exact test/lint/type-check results**: 
  - `pytest`: 1311 passed.
  - `ruff format / ruff check`: 0 errors.
  - `mypy`: 0 issues across `src/`.
- **Dependencies**: Explicitly, no framework-specific dependencies (e.g. LangGraph, CrewAI, Anthropic, OpenAI) were introduced into the core runtime.
- **Explicit non-goals**: This PR sets the foundation but does *not* implement OpenAI function calling, Anthropic tool_use, LangGraph, or CrewAI adapters.
